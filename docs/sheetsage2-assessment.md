# SheetSage2 assessment — 2026-09-20

SheetSage2 is a pretrained transcription model/inference release, not a downloadable labeled audio training corpus. Its melody-and-chord output is relevant to Piano Scribe's requested piano arrangements. It exports editable ABC, MIDI and timed annotations, with optional piano previews. This makes it a candidate transcription engine to evaluate if suitable commercial rights become available. [Model card](https://huggingface.co/m-a-p/SheetSage2)

The published melody benchmark uses pitch classes, so octave errors are not penalized as they are in our exact-pitch note evaluation. Reported scores therefore do not establish comparable piano-note accuracy. A licensed evaluation would need exact-pitch precision/recall, onset/release accuracy, accompaniment errors, and listening comparisons across multiple songs. [Benchmark definitions](https://huggingface.co/m-a-p/SheetSage2#-benchmarks)

The model card specifies CC BY-NC 4.0 weights. The required MERT-v2-FullSong parent also has non-commercial weight terms. This project is potentially commercial: do not integrate these weights or use them as a commercial training teacher without separate permission covering the intended uses and parent model. Fine-tuning does not itself remove the restriction. The repository's LICENSE header mentions MERT rather than SheetSage2 specifically; clarify that packaging detail with the publisher as part of any license request. [License](https://huggingface.co/m-a-p/SheetSage2/blob/main/LICENSE), [dependency notices](https://huggingface.co/m-a-p/SheetSage2/blob/main/THIRD_PARTY_NOTICES.md)

No weights or executable remote model code were downloaded or integrated for this assessment. Continue correcting and evaluating the existing commercially compatible training pipeline. Separately, a melody-plus-chord arrangement architecture is worth testing; it may reduce unnecessary accompaniment detail, but that is a hypothesis requiring evaluation.
