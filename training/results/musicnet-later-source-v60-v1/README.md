# Audited later MusicNet fitting-source acquisition

This stage retains the 49 fixed 20-second passages from 20 fitting-only parent
performances identified by the V59 symbolic source audit. It streams the pinned
11,097,394,998-byte original MusicNet archive without storing that full object.
Completion requires its exact MD5 and SHA-256, the publisher's CC BY 4.0 grant,
original source sample clocks and bit-identical reconstruction of the earlier
verified training crops. Only the predetermined later waveforms and unchanged
labels are retained. All other archive members are streamed past for whole-object
verification; validation/reserved/consumed waveforms are not retained or decoded.

No transcriber or model inference runs here. The ongoing V59 fitting study still
uses its frozen 2,302 recordings. These new passages remain outside fitting
until acquisition, native waveform/MP3 timing and strict preparation audits pass.
Source IDs retain their original auditor's v59 prefix; this acquisition stage
has a separate v60 producer/version and never changes that original assessment.

Twenty focused tests pass for bounded reading, exact crop bytes, malformed clocks,
archive identities and immutable partial reuse. The exact 49-crop/20-parent source
contract is verified before transfer. Acquisition is preregistered and pending.
