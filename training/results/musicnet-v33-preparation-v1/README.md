# MusicNet V33 preparation evidence

This is preparation evidence, not a trained candidate or accuracy claim. MusicNet
acquisition remains in progress. Its original complete archive must pass the
publisher checksum before observations or fitting begin.

The fitting baseline contains all 908 existing fixtures. The consumed regression
baseline contains all 469 fixtures, including the prior 77 first-pass recordings.
Applying the released V32 filter retains original event clocks and all physical
acoustic windows. Local feature caches remain excluded from Git; their complete
manifests and preparation plans are hashed here.

Both V33 profiles exactly reproduce the actual released V32 checkpoint before
learning on 24 evenly spaced fitting fixtures. Approved weights and normalization
remain frozen. The full framework suite passed 846 tests with 6 skips.

No user uploads were processed, no saved scores regenerated, and no new weights
were installed. The released V32 website remains active.
