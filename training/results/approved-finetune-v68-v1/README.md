# Guarded fine-tuning of the existing pitch-support features

V68 trains the existing 3265 support-branch parameters (presence convolutions, context conditioner and final readout) of approved V43. The original note-rejection classifier, architecture, normalization and inference thresholds stay unchanged. This tests whether learning better support features can improve beyond V66/V67's thirteen-parameter readout calibration.

A fitting-only teacher-peak margin loss protects labeled KEEP notes and candidates carrying known interior pitch support. Stronger known-absence loss targets unsupported notes. After each epoch, every protected training candidate is explicitly checked. Unsafe support-parameter updates are reduced by halves up to twelve times; if no checked fraction is safe, the exact previously accepted weights are restored. Nonlinear interpolation is never assumed safe without checking. These are teacher-behavior safeguards, not newly invented acoustic or duration labels. Unknown-frame masks and original note labels stay unchanged.

Two independently initialized profiles retain 25% and 75% of the approved teacher's decision margin. All 2302 training and 618 validation recordings and original partitions remain mandatory. Both validation policies must preserve genuine note identities, attacks, holds, coverage and timing while achieving positive overall, real-piano, NRG-CP and isolated-pitch gains. Only one winner across V66–V68 may access all 603 consumed regressions and then one fixed 40-MP3 first pass. No runner-up after failure; full runtime parity is mandatory before release.

All four protocols were registered before fitting. The full code suite passed 2094 tests (7 skipped, 5 warnings). No new audio was downloaded and no user audio or saved score was processed. Both profiles completed all 100 epochs with no qualifying validation winner. Every validation preservation check passed, but neither profile removed any additional false notes or improved any validation family. The quarter-margin guard restored the previous accepted state in 96 epochs, and the three-quarter-margin guard did so in 97 epochs. This is a stalled optimization result, not an accuracy improvement. No consumed regression or fresh data was opened, and no model was exported or deployed.

Detailed per-recording diagnostic JSON is stored as deterministic gzip archives. `diagnostic-archives.json` records both compressed and uncompressed SHA-256 values; every archive was verified against the unchanged native run output. Summaries and selection results remain plain JSON.
