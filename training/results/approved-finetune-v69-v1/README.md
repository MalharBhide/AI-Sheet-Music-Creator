# Train on decisions that actually depend on pitch support

V69 continues approved V43 support-feature fine-tuning with the same 3265 parameters and immutable rejection classifier, normalization, architecture and inference thresholds. V68 preserved validation quality but repeatedly rolled back updates and gained nothing. Its guard protected over 53,000 support scores even when the immutable note classifier would keep the candidate without a support veto.

The new guard protects labeled KEEP or known-positive-interior coverage candidates only when an original normal or strict KEEP decision depends on the support veto. An immutable rejection score below the relevant threshold cannot newly reject a note, so protecting its support score is redundant. A conservative 1e-6 rejection-score band covers float32 sigmoid/softmax rounding. Each batch includes 26 fitting-only protected draws and 230 ordinary fitting draws when dependencies exist; otherwise it uses 256 ordinary draws. Teacher decision-margin weight is 64. Both profiles retain the registered 25%/75% teacher margin, and every epoch checks all dependent training decisions before accepting an update. Unsafe steps are explicitly checked at decreasing fractions or restored exactly; nonlinear interpolation is never presumed safe.

This changes fitting constraints and sampling only. No note or frame labels, inference thresholds, validation partitions or release requirements are relaxed. Every 2302 training and 618 validation recording remains mandatory. Only one qualifying winner across V66–V69 may open consumed regressions and fresh tests; no runner-up after failure. No user audio, saved scores, new downloads or new architecture.

Protocols were frozen before fitting. Focused tests: 81 passed. Full suite: 2175 passed, 7 skipped, 5 warnings. Both profiles completed 100 epochs (native exit 0), but no checkpoint qualified. The guard identified 61 fitting candidates whose original keep decision depended on a support veto. At epoch 100 the quarter-margin profile removed 6 false notes in normal mode and 1 in strict mode, but failed normal-mode pitch-coverage preservation on two recordings. The three-quarter-margin profile removed 2 in normal mode and 1 in strict mode, with one normal-mode preservation failure. No regression or fresh data was opened and no weights were exported or deployed.

Detailed per-recording diagnostic JSON is stored as deterministic gzip archives. `diagnostic-archives.json` records both compressed and uncompressed SHA-256 values; every archive was verified against the unchanged native run output. Summaries and selection results remain plain JSON.
