# Fine-tune the approved model within the disk limit

The user requested local training below 25 GB and improvements to the existing
model. The initializer copies the released V43 weights and original fitted
normalizer exactly, retaining the 12-channel architecture and presence veto.
The original selected training checkpoint is bit-identical to this initialization.
A generated numeric unit fixture verifies finite gradients and a real optimizer
step; this is not dataset training or evidence of transcription accuracy.

The storage preflight reserves peak simultaneous stage bytes before acquisition.
It counts all files under the training root, rejects unaudited symlinks, and
protects a minimum free-space reserve. It is not an OS quota; callers must
serialize bounded writers and repeat preflight for each preparation stage.
No large new dependencies or Docker images were downloaded.

Restoration of the original licensed MusicNet excerpts has started with a 2 GB
stage reservation. The entire archive is streamed, not stored. Completion, source
checksums and provenance must be verified before training. Other required fitting,
validation and consumed-regression inputs also require restoration; source
partitions and release gates must not be weakened to fit the disk budget.
V58/V59 failed joint-study checkpoints are not fine-tuning initializers.
No user uploads or saved scores are processed, and no weights are deployed.
