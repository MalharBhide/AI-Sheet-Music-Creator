# V33 release preparation

These are preparation checks, not candidate accuracy or release evidence.
MusicNet fitting is still queued behind complete original-source verification.
The optional runtime is not imported or invoked by the current website route.
Its format-4 checkpoint reader preserves the released physical feature extraction
and eligibility, checks array shapes and confidence values, and requires an
explicit asset hash. No candidate asset is bundled.

Random learned weights pass exact training/runtime probability parity. Both
neutral profiles also reproduce the actual released V32 checkpoint exactly on
24 existing fitting fixtures. The full suite passed 862 tests with 6 skips.
Backend-only scope passed 326 tests with 6 skips without access to training
modules. A separate optional-package absence emulation passed 320 tests with
12 skips; this is not a fresh dependency installation or remote CI result. An
initial emulation incorrectly made find_spec raise for missing root packages;
that diagnostic was retained locally and corrected to Python's actual behavior.

CI now includes pinned CPU Torch and SciPy for the checkpoint/waveform unit tests.
The actual candidate must pass frozen validation, all consumed regressions, every
predeclared first-pass identity, export/runtime parity, native integration and
source/asset review before installation. The optional verifier inventories every
fitting/regression/first-pass event and independently recomputes first-pass
physical features, both confidence masks and all normalization values.

No user uploads or saved scores were processed. The released V32 model and the
original engraving remain unchanged.
