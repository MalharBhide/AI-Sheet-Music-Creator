# PDMX piano fitting preparation

This is new training-only source preparation, not a model release or an accuracy claim.
Two conflict-free, valid CC0 solo-piano arrangements of public-domain Scarlatti
works K.531 and K.208 are selected from the verified PDMX v9 archives. Publisher:
https://zenodo.org/records/15571083 . Dataset metadata is CC BY 4.0; selected uploaded
scores have explicit CC0 grants. No external performance/custom audio is used.

Seven exact-composer catalog rows were inspected symbolically. The clock screen
excludes ambiguous overlaps, nonpositive durations and pedal events. Other sources
also have uncertain work IDs, harpsichord intent or modern-edition provenance.
Program zero and catalog duplicate groups are insufficient identity checks.
The two selected sources explicitly match the score grant, composer and solo-piano
metadata; their whole composer is reserved for fitting only. Existing MusicNet,
Mutopia and Vienna manifests do not contain Scarlatti. No related work is newly
assigned to validation or test.

The fixed preparation renders complete works with the pinned licensed piano and
actual PPQ tempo maps before fixed 24-second waveform crops and three dynamics /
MP3 variants. It never retriggers a crossing held note. Only complete natural key
commands inside each crop supply attack/release references; crossing keys supply
clipped pitch support. First/last 2.5 seconds retain the existing protection policy.
These are synthetic command and damping labels, not human timing or pedal truth.
The sampled instrument is shared with NRG-CP; no timbre independence is claimed.

All 1,156 backend/training checks pass, six opt-in skips and five dependency warnings.
Preparation has not yet completed. No consumed/fresh test or user audio is processed;
website weights remain V43. Later model training retains all existing validation,
603-recording consumed, independent fresh and runtime release gates.
