# Original recording dynamics V44 — withheld

Both predeclared profiles completed 100 epochs on 1,221 fitting recordings,
with 345 validation recordings. The added 448 MP3 phrases use original NSynth
velocities 25, 50, 100 and 127 on the same disjoint training/validation instruments.
All eight authored articulations remain. Long samples retain the supplied
three-second key hold and full one-second decay; shorter gates are explicitly
authored, not claimed human releases. NSynth is licensed CC BY 4.0.

None of the 144 predeclared validation settings passed every recording's gates.
Some settings reduced extra notes but also lost required notes or restored errors
already removed by V43. The smallest normal-policy failure count was nine.
Lower fitting loss did not establish better transcription quality. No candidate
was selected, and no new model was exported or deployed. V43 remains the approved
website asset. The 603 consumed regressions and fresh seeds 289101–289140 were
not read for this study; the fresh seeds remain unconsumed.

The evaluator compares with released V43, checks restored notes explicitly, and
protects exact reference-matched prediction identities, attacks, holds, pitch
support, retained clocks, fixed-pair timing and chords. A nearby replacement may
not hide a lost required note. The V43 baseline helper matched the actual runtime
exactly on 2,127 fitting-note observations. Complete source/data audits and
checkpoint hashes are retained here; audio, caches and checkpoints stay local.
All 992 backend/training preflight tests passed, with six skips. No user uploads
or saved scores were processed. This failed validation study does not change the
website model or its confidence thresholds.
