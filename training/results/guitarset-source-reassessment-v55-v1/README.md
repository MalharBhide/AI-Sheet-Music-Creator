# GuitarSet source reassessment

The official Zenodo metadata confirms CC BY 4.0, but this corpus is already used
by the existing fitting/validation/consumed data pipeline. It is not a new source,
and no recordings or annotations were admitted to another split. A redundant
annotation download was started before the duplicate-source check and is not used.
No annotations are parsed and no audio is acquired or inferred for this assessment.

Publisher: https://zenodo.org/records/3371780
Source website: https://guitarset.weebly.com/
Known alignment errors: https://github.com/marl/GuitarSet/issues/5
Known duplicate note: https://github.com/marl/GuitarSet/issues/4

Existing source grouping and all release gates remain unchanged. This assessment
provides no new accuracy evidence and no model weights are deployed.
