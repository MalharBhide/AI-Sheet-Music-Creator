# Training-only KEEP constraints for the approved piano model

V66 fine-tunes the existing thirteen final support readout parameters of approved V43. The feature extractor, note-rejection head, float32 normalization, and inference policy stay unchanged. Previous V65 trials reduced false notes but also lost genuine notes. This experiment projects each epoch's readout update onto halfspaces constructed only from labeled KEEP training candidates: their approved peak support retains a fixed fraction of the original margin above the normal or strict veto. Two independently initialized profiles retain 25% and 75% of that margin.

The constraints protect teacher decisions, not human acoustic-frame or duration truth. They can include the peak of a KEEP note whose frame labels are unknown, but do not change supervised frame masks or manufacture frame labels. REMOVE notes never enter the constraints. Every projection checks all constraints after a float32 round-trip. Original weights provide a feasible fallback. This guarantees the checked fitting constraints, not preservation on unseen recordings; the full validation and release gates remain essential.

No new dataset or audio was downloaded. All 2302 training and 618 validation recordings retain their original partitions. Both policies must preserve every genuine note identity, attack, hold, coverage and timing, and improve overall, real-piano, NRG-CP and isolated-pitch results. Only one complete validation winner may open all 603 consumed regressions, then the one fixed 40-MP3 first pass, followed by complete runtime parity. No user audio or saved score is processed.

The four protocols were registered before fitting. Full tests: 1928 passed, 7 skipped, 5 warnings. Both profiles completed 100 epochs (native exit 0). Neither qualified at any stage. At epoch 100, the quarter-margin profile removed 7 false notes in normal mode and 4 in strict mode, but normal mode lost reference pitch coverage on 3 recordings. The three-quarter-margin profile removed 2 in normal mode and none in strict mode, with one normal-mode preservation failure. Neither improved NRG-CP or isolated-pitch validation. No consumed regressions or fresh tests were opened, no candidate was exported, and approved website weights remain unchanged. All 53,052 teacher-supported labeled KEEP fitting constraints were checked after every epoch; this did not guarantee generalization to held-out pitch coverage.

Detailed per-recording diagnostic JSON is stored as deterministic gzip archives. `diagnostic-archives.json` records both compressed and uncompressed SHA-256 values; every archive was verified against the unchanged native run output. Summaries and selection results remain plain JSON.
