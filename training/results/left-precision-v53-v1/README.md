# V53 new piano-data fitting study

This predeclared study trains two fresh width-20 boundary-conditioned frame and
rejection models on 2,122 fitting recordings, including 45 new PDMX piano MP3
windows. It inherits no V52 checkpoint and does not retune the failed pair.
The complete Scarlatti composer group is fitting-only; unchanged validation
contains 381 timed and 237 instrument-held-out pitch-only clips. Each model
fits its normalizer on labeled fitting candidates only. Real-piano fitting loss
has predeclared 4x/8x emphasis, renormalized over fitting candidates.

The release gates are unchanged: each recording must preserve genuine note,
pitch support, attacks, holds, exact matched identities, fixed timing, repeated
spacing, chords and unsupported duration. Immutable V43 output permissions mean
no rejected notes can be restored. Unchanged V38 release correction sees full
context before deletion. At both policies require separate positive overall,
real-piano, NRG-CP and TinySOL wrong-pitch benefits. Only one frozen validation
winner may reach all 603 consumed regressions, then an untouched 40-clip first
pass and portable/native runtime checks. No runner-up or retuning after failure.

No user uploads/saved scores or test data are used for fitting. Website weights
stay V43. PDMX source and crop-clock provenance are separate preparation receipts;
synthesized clocks are not human performance labels or new instrument evidence.
