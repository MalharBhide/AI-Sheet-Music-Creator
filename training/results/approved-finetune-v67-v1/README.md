# Protect genuine pitch coverage while suppressing false notes

V67 extends V66's fitting-only halfspace constraints to candidates with known positive interior pitch support, even when the attack-based note label is REMOVE. The original note labels and frame supervision are unchanged. This addresses an important mismatch: removing a poorly attacked note can still erase a genuine held-pitch interval. Unknown command support and positive frames outside the candidate interior never introduce coverage constraints.

Both profiles start from approved V43 and fine-tune only thirteen existing readout parameters, preserving 25% or 75% of the original teacher decision margin. The network backbone, float32 normalization, note-rejection head, inference policy and all validation/release gates stay unchanged. No new data or user audio is processed. All 2302 training and 618 validation recordings remain mandatory. The held-out consumed and fresh regression sets stay closed until a complete validation winner is selected once under V66's comparison protocol; no runner-up may be tried after a regression failure.

Protocols were registered before fitting. Focused tests: 83 passed. Full suite: 2011 passed, 7 skipped, 5 warnings. Both profiles completed 100 epochs (native exit 0), with no qualifying checkpoint. At epoch 100 the quarter-margin profile removed 6 false notes in normal mode and 4 in strict mode, but failed normal-mode pitch-coverage preservation on three recordings. The three-quarter-margin profile removed 2 in normal mode and none in strict mode, with one normal-mode preservation failure. Neither produced real-piano, NRG-CP or isolated-pitch gains. No regression or fresh data was opened and no weights were exported or deployed.

Detailed per-recording diagnostic JSON is stored as deterministic gzip archives. `diagnostic-archives.json` records both compressed and uncompressed SHA-256 values; every archive was verified against the unchanged native run output. Summaries and selection results remain plain JSON.
