# Verified new piano source

The complete original Oxford MIDI-test package passed its ZIP CRC checks and
HTTP length check. SHA256 and publisher HTTP identity are retained; the publisher
supplies no separate archive checksum. The bundled CC BY 4.0 license exactly
matches its separately published copy. Credit A. S. Koepke, O. Wiles, Y. Moses
and A. Zisserman, Sight to Sound, ICASSP 2020.

Eight original pairs are reserved as one pianist group. No predictions or MIDI
label interpretation have been performed, and this source is not included in
the frozen V33 MusicNet first pass. The raw ZIP remains excluded from Git.
The full current suite passed 852 tests, with 6 skips.

The local sequential MusicNet study waits for the exact existing acquisition
process and validates the original complete source before observation/fitting.
Its original queued command and driver are archived here for reproducibility.
It may run candidate checks but never exports or installs weights. An initial
queue attempt refused the host PID before any phase was started; the active
driver uses the observed container PID. Do not rerun this archived driver.
