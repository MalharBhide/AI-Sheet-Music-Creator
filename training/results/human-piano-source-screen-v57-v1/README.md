# Additional human piano data screening

Publisher-page review only; no audio, MIDI, note annotations or checkpoints were
acquired. This screen does not change V57's frozen fitting or test population.

| Candidate | Publisher evidence | Decision for this potentially commercial service |
| --- | --- | --- |
| [SMD MIDI-Audio Piano Music](https://audiolabs-erlangen.com/resources/MIR/SMD/midi) | CC BY-NC-SA 3.0 | Exclude from new fitting. |
| [IDMT-PIANO-MM](https://www.idmt.fraunhofer.de/en/publications/datasets/piano-mm.html) | CC BY-NC-ND 4.0; evaluation use | Exclude from new fitting. Public-domain compositions do not remove the recording restriction. |
| [PianoVAM](https://huggingface.co/datasets/PianoVAM/PianoVAM_v1) | Dataset card specifies CC BY-NC-SA 4.0 | Exclude from new fitting. A paper's different publication license is not the dataset grant. |
| [SKY-Piano](https://joonhyungbae.github.io/skypiano/) | Project describes per-modality licensing tied to participant consent | Not admitted: this screen has not established the specific audio and MIDI grant. No conclusion about eventual suitability without those terms. |

The screen was conducted on 2026-10-13. Existing suitable licensed data and the
new native-audited Keynata fitting cohort remain the only inputs to V57.
